TSMG Repair Video Library

Public site: https://thomasuzda.github.io/tsmg-repair-videos/
Ready queue: https://thomasuzda.github.io/tsmg-repair-videos/#ready-for-approval

25 saved films and the original 88-topic build list. Open a film to watch it,
approve the exact version, or mark Needs work and add shared notes.
Approval decisions persist centrally in the existing shared notes service,
keyed by video ID, version and movie SHA256. New versions start unapproved.
These are shared visitor decisions, not verified identities or automation authority.
All old movies, credits, notes and topic mappings remain preserved.
